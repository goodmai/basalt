# Техническое ревью проекта GemmaServer (Обновлено)

## 1. Текущее состояние и Прогресс
Проект успешно развивается в сторону production-ready решения для локального инференса на Apple Silicon (v0.2.0-rc). Основной архитектурный паттерн с использованием `actor` для оркестрации запросов (`ModelOrchestratorActor`) доказал свою эффективность: он обслуживает как MCP, так и REST транспорты без гонок данных. 

### Успешно внедренные новшества:
1. **Профилирование и Контроль памяти (Epic 2):** Реализован `ContextDegradationProfiler` для замера метрик на разных размерах контекста. Внедрен `TokenBudgetCalculator`, который динамически пересчитывает доступный размер контекста (`maxTokens`) на основе свободной памяти (через `host_statistics64`), предотвращая OOM.
2. **CI/CD и Тестирование (Epic 3):** Настроен GitHub Actions пайплайн для автоматического прогона тестов и бенчмарков (TTFT, TPS) на M-процессорах при каждом PR. 100% покрытие unit-тестами критичных модулей.
3. **UX Командной строки (Epic 4.2):** Реализовано интерактивное меню выбора модели при вызове `gemma chat` без аргументов, что сильно упрощает порог входа.
4. **Интеграция Агентов (Epic 6 / 5.2):** Внедрен `AgentCapabilityAnalyzer`, способный парсить `.md` документацию агентов (форматы Anthropic и Gemini) и извлекать спецификации доступных инструментов (Tools).

## 2. Архитектурный анализ и Точки роста

### 2.1. Безопасность и Аудит (Epic 5 - CRITICAL)
В данный момент проект переходит к фазе полноценного релиза, однако **Epic 5 (Security & Dependency Audit)** еще не начат. Это критично:
*   Необходимо провести жесткий аудит `AuthService` (перевести хеширование на Argon2/Bcrypt, если текущее решение недостаточно криптостойко, проверить хранение JWT).
*   Проверить все зависимости (`mlx-swift`, `hummingbird`, `jwt-kit`) на наличие CVE через OSV API.
*   Обеспечить защиту от CWE-20 (Improper Input Validation) и Path Traversal.

### 2.2. Распространение (Distribution - Epic 4.1)
Отсутствует удобный механизм установки. Пользователям приходится клонировать репозиторий и запускать `swift build`.
*   **Решение:** Требуется написать Bash-скрипт установки `install.sh` и подготовить `Formula/gemma.rb` для Homebrew, чтобы пользователи могли устанавливать сервер через `brew install gemma`.

### 2.3. Нумерация в PLAN.md
Замечена небольшая путаница в нумерации `PLAN.md`: секция "Epic 6: MCP Plugin Marketplace & Agent Integration" содержит подзадачи, пронумерованные как 5.1, 5.2, 5.3 (хотя должны быть 6.1, 6.2, 6.3). Это нужно исправить для поддержания чистоты документации.
