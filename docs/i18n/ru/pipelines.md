# Пресеты конвейеров и режимы памяти

> Languages: [English](../../pipelines.md) · **Русский** · [中文](../zh/pipelines.md) · [Español](../es/pipelines.md) · [Français](../fr/pipelines.md) · [日本語](../ja/pipelines.md) · [Deutsch](../de/pipelines.md) · [한국어](../ko/pipelines.md) · [Bahasa Indonesia](../id/pipelines.md)

`/v1/pipeline` (MCP `basalt_pipeline`) выполняет восприятие (OCR, речь) → принятие решения (System One) → ответ (чат-модель) в одном процессе. Пресет заполняет флаги `serve` для встроенного профиля; любой явно указанный вами флаг имеет приоритет:

```bash
basalt serve --pipeline-preset document-qa     # PaddleOCR-VL, System One by readout of the chat model, the chat model
basalt serve --pipeline-preset voice-agent     # Nemotron Transcribe and the chat model
basalt serve --pipeline-preset support-triage  # System One with the ticket questions, and the chat model
```

В качестве чат-модели используется Gemma 4 12B или Qwen3.8-27B 3-bit, если она помещается рядом с остальными моделями с запасом в 8 ГБ. Флаг `--pipeline-memory` задаёт способ разделения памяти между моделями:

- `resident` держит загруженными все модели одновременно, поэтому их суммарный объём должен помещаться в рабочий набор (working set).
- `sequential` загружает каждый модуль восприятия для своего этапа и выгружает его после завершения. Чат-модель остаётся загруженной, если помещается рядом с самым крупным модулем восприятия; в противном случае она выгружается на время его работы. В память должен помещаться только самый крупный этап плюс 2 ГБ, поэтому на Mac с меньшим объёмом памяти тяжёлый набор моделей всё равно запустится, хотя и медленнее. Последовательные запросы к конвейеру выполняются по одному, а обычные запросы к чату ожидают завершения переключения моделей.
- `auto` (по умолчанию) выбирает `resident`, если сумма помещается в память, в противном случае — `sequential`, и отклоняет запуск только если отдельный этап слишком велик сам по себе.

Измерено на M4 Pro, 24 ГБ (рабочий набор 19.1 ГБ), release-сборка, коммит 1921c3c. У второго запроса кэш страниц уже прогрет:

| Пресет | Модели | План | Запрос 1 | Запрос 2 | Из них переключение | Пиковое потребление памяти |
|---|---|---|---|---|---|---|
| voice-agent | Gemma 4 12B 11.0 GB + Nemotron Transcribe 30B-A4B 14.9 GB | sequential (для resident нужно 25.9 ГБ), чат-модель выгружается на время распознавания речи | 21.4 с | 8.6 с | 6.0 с / 5.4 с | 15 ГБ |
| document-qa | Qwen3.8-27B 3-bit + PaddleOCR-VL 1.5 | `--pipeline-memory sequential`, чат-модель остаётся загруженной | 23.2 с | 11.2 с | 0.4 с / 0.2 с | 14 ГБ |
