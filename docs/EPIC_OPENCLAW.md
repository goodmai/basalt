# Epic: OpenClaw Integration — Multi-modal Agent Router 🦾

## Vision
Превратить Gem CLI в центральный узел (Router) для мультиагентных систем, способный не только маршрутизировать текстовые запросы, но и поставлять обработанные данные (аудио, видео, OCR) через единый интерфейс `gem openclaw`.

## Архитектурные заимствования из OpenCLI
На основе анализа `.opencli`, мы внедряем следующие паттерны:
1. **Task-Based Routing**: Разделение инференса на атомарные задачи (ASR, TTS, VLM, OCR).
2. **Unified Data Provider**: Gem выступает как источник контекста для OpenClaw агентов.
3. **Hardware-Aware Dispatch**: Использование Fit Score для выбора между локальным инференсом (MLX) и облачным fallback.

## Декомпозиция фаз

### Фаза 1: Инфраструктура OpenClaw (Router Core)
- [ ] **Команда `gem openclaw`**: Реализация базового REPL/Daemon режима для взаимодействия с внешними агентами.
- [ ] **Agent Router Logic**: Маршрутизация на основе интента (текст → LLM, голос → ASR).
- [ ] **Context Injection**: Поставка локальных данных (файлы, переменные) агентам OpenClaw.

### Фаза 2: Аудио-пайплайн (ASR/TTS/STS)
- [ ] **ASR (Automatic Speech Recognition)**: Интеграция Whisper (MLX) для преобразования речи в текст.
- [ ] **TTS (Text-to-Speech)**: Реализация генерации аудио (Matcha-TTS/VITS) для озвучки ответов.
- [ ] **STS (Speech-to-Speech)**: Сквозной пайплайн "Голос-Текст-Голос".

### Фаза 3: Визуальный интеллект (OCR/VLM/Video)
- [ ] **OCR Engine**: Пакетная обработка скриншотов и PDF (PaddleOCR или DeepSeek-OCR).
- [ ] **VLM (Vision Language Models)**: Поддержка Qwen2-VL или Llama-3-Vision для анализа видеопотока.
- [ ] **Video Frame Extraction**: Извлечение и описание ключевых кадров для контекста агента.

### Фаза 4: Оркестрация и Протоколы
- [ ] **A2A (Agent-to-Agent)**: Реализация протокола для общения с другими OpenClaw-совместимыми системами.
- [ ] **Streaming Multiplexer**: Передача потоковых данных (аудио/видео) между Gem и агентом.

---

## Технические детали реализации
- **Интерфейс**: `gem openclaw --task <task> --input <file>`
- **Транспорт**: gRPC или JSON-RPC 2.0 поверх stdio (совместимость с MCP).
- **Backend**: MLX Metal для ускорения на Apple Silicon.

## Риски и проверки
- **Latency**: Задержка при переключении между ASR и LLM (решается через пре-лоадинг).
- **RAM Pressure**: Мультимодальные модели требуют значительной памяти (требуется интеграция с `fit` command).
- **Privacy**: Защита аудио/видео данных при передаче внешним агентам.
