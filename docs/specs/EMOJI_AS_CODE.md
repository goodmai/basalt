# Спецификация: Emoji as Code (Emoji Feedback System)

## Обзор
Система Emoji Feedback предназначена для улучшения взаимодействия с пользователем в терминале, делая вывод более структурированным, выразительным и легким для визуального сканирования. Мы адаптируем стандарт **Gitmoji** для CLI-сообщений, логов и статусов агента.

## Стандарты Emoji

### 1. Категории сообщений
| Emoji | Назначение | Использование в Gem CLI |
| :--- | :--- | :--- |
| ✨ | Новая функция / Возможность | Уведомление о загрузке нового плагина или модели. |
| 🐛 | Исправление ошибки | Логи исправления кода агентом в реальном времени. |
| 🚀 | Деплой / Запуск | Сообщения о запуске локального сервера или сервиса. |
| ⚡️ | Производительность | Результаты бенчмарков и метрики TPS. |
| 📝 | Документация | Уведомление о создании или обновлении `.md` файлов. |
| 🎨 | Структура / UI | Сообщения о рендеринге таблиц и интерфейса. |
| 🔐 | Безопасность | JWT аутентификация и проверка разрешений. |
| 📦 | Зависимости | Процесс скачивания весов моделей с HF. |
| ✅ | Тесты / Успех | Успешное выполнение команды или прохождение тестов. |
| ⚠️ | Предупреждение | Нехватка RAM или высокая нагрузка на GPU. |
| 🚨 | Критическая ошибка | Ошибки инференса или падение сервера. |
| 🧠 | Мышление / AI | Статус «Thinking process» (CoT) агента. |

## Технические требования
1. **TTY Detection**: Эмодзи должны отображаться только в интерактивных терминалах. При перенаправлении вывода в файл использовать текстовые префиксы (например, `[INFO]`, `[SUCCESS]`).
2. **Fallback**: Для старых терминалов обеспечить ASCII-аналоги или Unicode-символы широкой совместимости.
3. **Accessibility**: Использовать `aria-label` аналоги в документации и структурированных логах.

## Интеграция в код
Все сообщения должны проходить через `TerminalUI.swift` для централизованного форматирования.
```swift
TerminalUI.print("✨ Загружена модель Qwen 3.5-4B")
```
