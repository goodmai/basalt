# Чеклист интеграции OpenClaw

Этот чеклист фокусируется на реализации Gem CLI как мультимодального роутера.

## 🏗 Мультимодальные фичи
- [ ] **Unified Dispatcher**: Реализация `OpenClawController` для управления жизненным циклом сессий.
- [ ] **Audio Engine (ASR)**:
    - [ ] Интеграция Whisper Core (Tiny/Base/Large-v3).
    - [ ] Поддержка VAD (Voice Activity Detection) для автоматического начала инференса.
- [ ] **Voice Engine (TTS)**:
    - [ ] Реализация `TTSProvider` с поддержкой локальных весов.
    - [ ] Потоковая генерация аудио для минимизации задержки.
- [ ] **Vision Engine (OCR/VLM)**:
    - [ ] Пакетная обработка изображений (Batch Inference).
    - [ ] Описание контекста скриншотов для агента.

## 🛠 Технические проверки (Audit)
- [ ] **Memory Isolation**: Каждая мультимодальная модель должна запускаться в изолированном контексте для предотвращения OOM.
- [ ] **Process Leakage**: Проверка на корректное завершение FFmpeg и других внешних утилит для обработки медиа.
- [ ] **IO Throughput**: Замер пропускной способности при передаче видеопотока через stdio-прокси.
- [ ] **Security (Privacy)**: Проверка того, что аудио-записи не сохраняются на диск во временные файлы без шифрования.

## 🔗 Интеграция
- [ ] **Fit Score Sync**: Автоматическое переключение качества моделей (Whisper Small vs Large) на основе доступной VRAM.
- [ ] **Emoji Logic**: Использование 🎙 для ASR, 🗣 для TTS, 👁 для Vision в CLI-выводе.
