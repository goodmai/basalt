# Evolution of neural network architectures, mathematical mechanisms and training algorithms (1958–2027)

A chronological monograph by **Aleksei Boklag** (Алексей Боклаг): one chapter per year from the Mark I perceptron (1958) to the sparse hybrid, full-duplex speech and recurrent-depth diffusion models of 2026–2027, with a glossary of tensor notation, summary tables of architectures and benchmarks (Appendix A), twelve reference PyTorch listings (Appendix B), a table of what basalt already runs (Appendix C) and a bibliography of 445 numbered sources.

The Russian text is the original. The other five official UN languages are translations made with AI assistance; where they differ, the Russian version is authoritative. Formulas are images in [images/](images/), shared by all languages.

**What basalt supports.** Appendix C (Приложение В) of each file maps the monograph's model types and mechanisms to basalt v0.13.0: supported, partial, not yet, or out of scope, with the file, flag or issue for each. The checklist for the monograph's problem book is tracked in a GitHub issue linked from the appendix.

Also on the [website](https://bas-alt.vercel.app/monograph/) and on [Hugging Face](https://huggingface.co/datasets/goodmai/neural-network-evolution-1958-2027).
